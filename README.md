# LLogo

This is an implementation of the classic Logo software from scratch in C. It uses Raylib to render the graphics.

# How to run

- Install Raylib on your machine.
- Clone this repository
- Open the repository in terminal
- Run  ``` make build ```
- Run  ``` make run ```

# Commands implemented

- fd
- bk
- rt
- lt
- setxy
- home
